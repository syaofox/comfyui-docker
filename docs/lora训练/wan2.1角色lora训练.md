1. timestep type 选sigmod,如果数据图都是近景照片的话



针对 Wan 2.1 的角色 LoRA 训练，使用“图片方式”在 Ostris AI Toolkit 中是**完全可行且性价比很高**的方案。本质上是用多张角色图片，让模型学习该角色的身份特征，从而在生成视频时保持角色一致性。

### 📁 数据集准备：图片是核心
用图片训练 Wan 2.1 角色 LoRA，数据集的准备是关键。

*   **图片数量与质量**：准备 **10 到 20 张**角色图片就足够了，甚至 7-8 张也能开始。关键是图片要有多样性，包含角色的不同角度、表情、光照和背景，这样能帮助模型更好地泛化角色的三维特征。
*   **文件格式与命名**：图片格式支持 **JPG、JPEG、PNG**。每张图片需要配对一个**同名的 `.txt` 字幕文件**（如 `image1.jpg` 对应 `image1.txt`），放在同一个文件夹里。
*   **字幕（Caption）撰写**：字幕质量直接影响训练效果。
    *   **使用自然语言描述**：像日常说话一样描述图片内容，而不是堆砌标签。例如：“一个年轻女性，棕色长发，穿着红色毛衣，站在窗边微笑，柔和光线。”
    *   **包含关键信息**：描述角色的**发型、发色、瞳色、服装、表情、动作、拍摄角度（全身/特写）和背景**等具体细节。
    *   **避免抽象词汇**：尽量不要使用“美丽”、“氛围感”这类主观或模糊的词汇。
    *   **使用触发词**：在字幕中加入一个**独特、无意义的触发词**（如 `p3r5on`），例如 “`p3r5on`，一个年轻女性...”。这样在推理时，只要输入这个触发词，就能稳定激活角色特征。

### ⚙️ 核心配置参数
在 AI Toolkit 的配置中，以下几个参数对于图片训练 Wan 2.1 角色 LoRA 至关重要。

| 参数 | 推荐设置 | 说明 |
| :--- | :--- | :--- |
| **`arch`** | `wan21` | 在 `model` 部分指定，告诉工具你正在训练 Wan 2.1 架构。 |
| **`noise_scheduler`** | `flowmatch` | Wan 2.1 采用流匹配（Flow Matching）架构，**这是必须且唯一正确的选项**。 |
| **`timestep_type`** | `sigmoid` 或 `weighted` | 官方示例配置使用 `sigmoid`，能让模型侧重中等噪声水平，有助于快速收敛和稳定训练。部分社区经验也会推荐 `weighted`，你可以从 `sigmoid` 开始尝试。 |
| **`timestep_bias`** | `balanced`（默认） | 对于角色 LoRA，建议先用 `balanced` 进行训练。如果后期感觉细节不够精致，可以尝试在训练末期切换为 `Low Noise` 来强化细节。 |
| **`network.linear`** | `32` | 这是 LoRA 的秩（rank），决定了模型的学习容量。对于角色训练，`32` 是一个均衡的选择。 |
| **`train.batch_size`** | `1` | 由于视频模型参数量大，显存占用高，通常从 `batch_size: 1` 开始训练。 |
| **`train.steps`** | `2000` 左右 | 官方示例推荐 **500 到 4000 步** 是一个不错的范围。具体步数取决于数据集大小，建议每训练 250 步保存一个检查点，然后测试哪个效果最好。 |
| **`datasets.resolution`** | `[632]` | 官方示例使用 `[632]`，这大约对应 480p 的分辨率。你需要根据显存情况调整，分辨率越高，对显存要求越大。 |
| **`model.name_or_path`** | Wan2.1 模型路径 | 需要指定为 Hugging Face 上的模型路径，例如 `Wan-AI/Wan2.1-T2V-1.3B-Diffusers` 或 14B 版本。 |

### 💡 训练建议与显存要求
*   **显存要求**：训练 Wan 2.1 **14B** 模型时，官方建议至少 **24GB 显存**，并使用 `quantize_te: true` 等量化技术来节省显存。如果使用 1.3B 小模型，对显存的要求会低很多。
*   **测试与迭代**：训练过程中，**每 250 步保存的检查点**都值得测试。通常早期的检查点可能效果不佳，建议从 1000 步左右开始测试，寻找效果最佳的版本。
*   **训练目标**：用图片训练出的 LoRA 主要学习的是角色的**外观和身份特征**。它能让 Wan 2.1 在生成视频时保持角色长相、服装等的一致性，但对于学习特定的**动作或运动模式**，效果可能不如直接用视频训练。

总的来说，用图片训练 Wan 2.1 角色 LoRA，核心是准备一个高质量、有多样性的图片数据集，并搭配自然、详细的字幕。配置上，务必确保 `arch` 为 `wan21`，`noise_scheduler` 为 `flowmatch`。
